# W5–6 CLI A 层阶段记录

## 当前状态

CLI A 层、术语表和 CLI SAFE 审阅已完成实现与本地验证。发布门禁仍未通过：S2、S3 在 A 层安装前后都被 Claude 服务端以 `403 Request not allowed` 拒绝，因此本阶段保持“进行中”，不进入 W7–8，不发布或推送。

## 已完成

- 新增 `patchers/cli-layer-a/`，实现 `install`、`status`、`restore`。
- 新增中文 statusline、`SessionStart` hook、中文回复 output style、用户级 `/zh-*` skills 和可严格校验的本地插件。
- 所有生成文案来自 `corpus/cli/layer-a.json`，补丁器代码不硬编码中文翻译。
- 用户配置写入前逐字节备份并校验 SHA-256；安装失败自动回滚。
- 已有 `statusLine`、`outputStyle`、hooks 和同名文件只保留、不覆盖。
- 若安装后用户继续修改配置，还原只移除仍与安装记录完全一致的新增项。
- 术语表达到 353 条，覆盖 slash 命令、工具名、常见错误、状态和设置项。
- `corpus/cli/2.1.112.json` 达到 405 条，其中 400 条经保守审阅标记为 SAFE；A 层不消费这些二进制候选，所以译文暂留空，避免在 W9–10 路线确定前提前生成未使用译文。
- 新增 CLI help 审阅脚本及 400 条决策证据。
- 若 `settings.json` 在安装过程中被其他进程修改，安装立即中止并保留新字节，不用旧备份覆盖并发修改。

## 冒烟测试

依据 `docs/SPEC.md` §5.1：

| 断言 | 结果 | 输出 |
|---|---|---|
| S1 `claude --version` | pass | `2.1.201 (Claude Code)` |
| S2 最小模型请求 | blocked | `Failed to authenticate. API Error: 403 Request not allowed` |
| S3 读取当前目录 `package.json` | blocked | 同一 403，请求未进入工具调用 |
| S2 还原后对照 | blocked | 原始配置仍返回同一 403 |

`claude auth status --text` 同时显示 Claude Pro 登录态。当前证据说明问题在账号或服务端授权链路，不是 A 层设置；本项目不修改登录或凭证配置。

## 已知限制

Claude Code `2.1.201` 未注册中文 skill / command 文件名，因此阶段提示中的 `/压缩` 不能按示例落地。最终使用 `/zh-compact` 等 ASCII 标识符和中文说明，不把不生效的中文命令写入用户配置。

## 门禁结论

DoD 中语料规模、可见中文、配置安全与还原均已满足；三条 CLI 冒烟测试尚未全绿。按仓库规则，本阶段不能标记完成，也不能发布或合并。解除 403 后只需重新安装 A 层并重跑 S2、S3；两项通过后即可更新阶段状态并进入 W7–8。
