# 简体中文翻译风格指南

本指南展开 `docs/PLAN.md` §4–5。若本文件与 `corpus/glossary.json` 冲突，以词表
和 CI 校验结果为准。

## 核心原则

1. 准确优先于自然，安全优先于覆盖率。
2. 原文简洁，译文也保持简洁；不增译、不解释、不发挥。
3. 用「你」，不用「您」。
4. 使用中性陈述句，不使用「哦」「呢」「啦」、波浪号、emoji 或网络用语。
5. `risk != SAFE` 的条目不翻译。

## 排版

| 规则 | 正确 | 错误 |
|---|---|---|
| 中文与英文之间加半角空格 | `按 Shift+Tab 切换` | `按Shift+Tab切换` |
| 中文与数字之间加半角空格 | `剩余 20% 上下文` | `剩余20%上下文` |
| 中文使用全角标点 | `失败：请重试。` | `失败: 请重试.` |
| 代码和路径保持原样 | `读取 package.json` | `读取 软件包.json` |
| 双语术语使用半角括号 | `压缩上下文 (compact)` | `压缩上下文（compact）` |

不得修改、翻译或重新编号 `{0}`、`%s`、`${name}` 等占位符。

## 语气与动作

| 原文 | 推荐 | 不推荐 | 原因 |
|---|---|---|---|
| `Cancel` | `取消` | `取消操作吧` | 不增译，不加语气词 |
| `Try again` | `重试` | `请再试一次` | UI 动作保持短 |
| `Permission denied` | `权限被拒绝` | `很抱歉，你没有权限` | 错误提示保持中性 |
| `Check for updates` | `检查更新` | `查找可用的新版本` | 不扩写 |
| `Loading` | `加载中` | `正在努力加载` | 不拟人化 |

同一操作全项目使用同一动词。已有词条必须复用 `corpus/glossary.json`，不能因为
局部语境自行创造同义译法。

## 何时保留英文

以下内容在双语模式中保留英文：

- 产品功能名：`Plan mode`、`compact`、`subagent`；
- 用户会复制搜索的错误或状态：`Permission denied`、`rate limit`；
- 官方文档高频词：`hook`、`MCP`、`skill`；
- 生态通用术语：`token`、`commit`、`prompt`。

格式固定为 `中文 (English)`，英文大小写必须沿用原文。通用 UI 动作、状态词和
常识技术词通常只保留中文。

## 终端与二进制约束

- 终端 `target` 的显示宽度不得超过原文。
- C 层译文的 UTF-8 字节数不得超过 `byte_budget`。
- B/C 层只使用 `target`，不使用更长的 `target_bilingual`。
- 无法得到准确且不超宽的短译文时，保留英文并维持 `UNKNOWN`。

## 提交前检查

- unit 是 `SAFE`；
- 译文未增加原文不存在的信息；
- 占位符数量、顺序和写法不变；
- 术语与词表一致；
- 中英文和数字之间有半角空格；
- 没有禁用语气词、emoji 或网络用语；
- 显示宽度和字节预算通过；
- `target_bilingual` 由项目规则生成，不手工创造另一套译法。
