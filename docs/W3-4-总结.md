# W3–4 Desktop 首发阶段记录

## 当前结论

Windows 非 MSIX Claude Desktop `1.18286.0` 的本地化补丁、状态检查和精确还原已经实现。D1–D4 已全部通过，[私有 v0.1.0 Release](https://github.com/skxxxkx666/claude-zh-bilingual/releases/tag/v0.1.0) 已发布。

## 交付内容

- Desktop 语料共 406 条：320 条 SAFE 已审阅并翻译，80 条 UNKNOWN、4 条 FRAGILE、2 条 DANGER 保持英文。
- 术语表共 110 条；双语模式按优先级最多保留两个可检索英文术语。
- `claude-zh install desktop --mode=zh|bilingual`、`restore desktop` 和 `status` 已实现。
- 修改前在 `%LOCALAPPDATA%\claude-zh` 创建逐文件备份并校验 SHA-256；安装中途失败会自动还原。
- Microsoft Store / 企业 MSIX 仅做只读识别并拒绝修改。
- tag 发布工作流只有在 D1–D4、语料验证标记和支持矩阵全部通过时才会生成 GitHub Release。
- tag 的 Release、Tests、Validate corpus 三条工作流全部成功；下载资产复核 SHA-256 为 `6c0777662e7dac3d79d8d2be6329cce68f9729940c351ac81b28ca35a86c6efe`。

## 补丁范围

补丁器只读取 `resources/app.asar` 中的版本号，不修改或重打包 ASAR。实际改动仅限外部 `resources/en-US.json`、生成的 `resources/zh-CN.json`，以及 `resources/ion-dist` 中与 SAFE 语料完全匹配的带引号 UI 字面量。

早期验证曾尝试重打包 ASAR，但复制环境启动后立即退出。Electron 的 ASAR integrity 会在归档头哈希不匹配时终止进程，因此正式实现改为完整性安全的外部资源策略，不修改 PE 资源、签名或 ASAR。参考 [Electron ASAR integrity](https://www.electronjs.org/docs/latest/tutorial/asar-integrity) 与 [Electron ASAR archives](https://www.electronjs.org/docs/latest/tutorial/asar-archives)。

## 当前限制

- 当前只适配 `1.18286.0`，版本不匹配会拒绝安装。
- 登录页等不在 320 条 SAFE 语料中的文案仍保持英文。
- Windows MSIX 与 macOS 不支持；不会为绕过平台保护而修改系统安装目录或签名。
- 仅允许从通过 `scripts/release_status.py --release-gate` 的 tag 构建 GitHub Release。
