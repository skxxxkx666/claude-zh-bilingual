# W9–10 CLI 原生层阶段记录

## 当前结论

CLI `2.1.220` 的 C 层无法正确承载中文，已经按红线停止；B 层真实 ConPTY 透传与
一条等宽 spinner 翻译可用，S1–S3 全绿。A 层继续作为默认稳定方案，B 层保持
实验性和低覆盖，不把“能改 ASCII”包装成“能安全汉化二进制”。

B 层命令、数据流和运行边界见 [pty-layer.md](pty-layer.md)。

## 原生 surface mapper

以 `cli@2.1.112` 的 400 条既有 SAFE unit 为输入，对 `2.1.220` 做两层证明：

1. source 必须位于 `.bun`，且命中 `tag = 9`、长度前缀和大小写精确内容；
2. source 必须在真实 `claude ... --help` 页面逐字出现。

结果：

| 指标 | 数量 |
|---|---:|
| 递归抓取帮助页 | 49 |
| 有合法 Bun 记录的既有 SAFE source | 353 |
| 批准为 `cli.help` | 86 |
| 批准的精确 occurrence | 124 |
| 保持 `PENDING` | 314 |

`PENDING` 中 267 条有原生记录但没有运行时 surface 证据，47 条没有合法独立记录。
它们没有被重新标成 SAFE。

真实 extractor 复跑共输出 1,713,378 条 occurrence；124 个映射结果与 review map
的精确偏移集合完全一致，缺失 0、额外映射 0。同文但未审阅偏移不会继承 surface。

## C 路线

### 结构与强制前置实验

Windows x64 样本：

- 版本：`2.1.220`；
- 大小：265,720,480 字节；
- SHA-256：
  `AF5BF1F1B2AADFFC768ECCD787084C6FDF9BA81624CBE96C1C6D9AC1A1550231`；
- 原始 Authenticode：`Valid`。

`.bun` 独立字符串记录为 8 字节 little-endian 头
`<tag = 9><byte length>` 加字符串内容。对 `Thinking` 的等长 ASCII、NUL 缩短和
空格缩短三种隔离实验均保持文件大小不变，S1–S3 全绿。

### 两个反证

- 改写 3 个合法 `Thinking` 记录后，强制 spinner 仍显示原文；这些记录不是实际
  spinner surface。
- 已审阅的 `Output the version number` 改为较短 ASCII 后，`--help` 确实显示
  新文本；说明 help mapper 找到了实际 surface。

随后把 5 个审阅过且满足 `byte_budget` 的帮助记录替换为中文。程序和 S1–S3 没有
崩溃，但中文被按 Latin-1 单字节语义解释并显示乱码。测试副本随即用已校验备份
还原，SHA-256 和 Authenticode 都恢复原值；临时生产 patcher 和未验证语料全部撤回。

因此 C 路线对中文判定失败。详细字节布局和乱码证据见
[binary-layout.md](binary-layout.md)。

## B 路线

### B1 零替换

基于 `node-pty` 的 Windows ConPTY 桥完成真实透传：

- 欢迎页颜色、Unicode 标志和清屏正常；
- `/help` 能打开、关闭和重绘；
- 输入、Esc、`/exit` 与退出码正常；
- resize 事件传给子 PTY；
- 不修改二进制、安装目录或用户设置。

### B2 等宽替换

只放行 `Thinking…` → `正在思考…`，两者终端宽度均为 9。真实 TUI 通过临时
`spinnerVerbs` 稳定触发后，中文可见，分隔线和输入列未移动。页脚
`manual mode on` 因单词之间存在 ANSI 光标移动而未命中，已从语料撤回，没有实现
跨 ANSI 猜测。

B 层随后执行：

- S1：`--version` 包含 `2.1.220`；
- S2：`-p "1+1"` 输出独立数字 `2`；
- S3：读取根目录 `package.json` 并输出 `claude-zh`。

三条全部通过，spinner unit 标记为 `verified_at = cli@2.1.220`。

### B3 长测方法

`verifier/cli-layer-b-soak.cjs` 在真实 ConPTY 中运行 30 分钟：

- 只发送一次无害消息触发 spinner；
- 每分钟轮换 `100×30`、`72×24`、`120×40` 三种尺寸；
- 每分钟打开并关闭 `/help`，持续触发全屏重绘；
- 仅记录计数、退出码和协议失败，不保存会话原文；
- 结束时先用 Esc 关闭可能打开的对话框，再发送 `/exit`，超时才强制终止。

机器结果写入 `report/W9-layer-b-soak.json`：实际运行 `1803.612` 秒，完成 29 次窗口缩放和 29 次帮助界面重绘，观察到 5322 个 ANSI 序列；目标译文命中 2 次，进程退出码为 0，未强制终止，协议失败为 0。真实终端首轮人工观察的错位次数为 0。

  应继续保持打开；

- Windows 以外平台尚未做真实 PTY 验证。
